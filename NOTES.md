# Week 7 — Class Design

## What I built

I built a Trotro Transport Management System using JavaScript classes.

The project includes:

- A "Trotro" parent class with a constructor.
- Methods for boarding and dropping passengers.
- A method for displaying a formatted summary.
- An "ExpressTrotro" child class that inherits from "Trotro".
- Three instances representing different transport routes.
- Method overriding to calculate express fares.

## What got me stuck

Understanding how inheritance works, especially the use of "extends" and "super()", was initially challenging. I also needed to understand how a child class can override a method from its parent class.

## Did I use AI?

Yes. I used ChatGPT to help me understand class design, inheritance, constructors. I reviewed the code and used the explanations to understand how the different parts work.
